# Writing and translation blocks

## Separate the three judgements

Writing feedback that mixes these teaches none of them:

1. **Communication** — did it convey what the learner meant?
2. **Correctness** — is it grammatical?
3. **Naturalness** — is it what a speaker would actually write?

Give each its own sentence, in that order. A message that communicates perfectly with two
case errors is a success with two corrections, not a failure.

## Require a rewrite

Feedback the learner does not act on is not learning. After corrections, ask for the
passage again — or the corrected sentences at minimum — and record the rewrite as a
*separate* attempt. The rewrite is where controlled production actually shows.

## Translation is a means, not the goal

Translation into the target language is a useful elicitation device for a specific form.
It is not a measure of communicative ability, and a translation attempt should claim no
more than `controlled-production`.

## What to record

- The first draft as one `attempt.observed` (`extended-productive`, `modality: writing`).
- The rewrite as a second attempt, with the help level that reflects the feedback given.
- One `correction.given` per pattern, not per instance: three occurrences of the same
  case error are one pattern with three occurrences, and the CLI folds them that way.
- `response` only within retention consent; the excerpt is what justifies the evidence.
